# Queaky STEM Toy PCB

A custom PCB implementation of the **Queaky STEM Toy**, designed using **KiCad 10**. This project recreates the original NE555 Timer-based circuit on a compact printed circuit board, replacing the traditional perfboard implementation with a cleaner, more organized, and reliable PCB design.

---

## 📖 Overview

The Queaky STEM Toy is a simple electronic project that generates a squeaky sound using the **NE555 Timer IC**. This repository contains the complete schematic and PCB layout designed in KiCad 10.

This project was created to learn the complete PCB design workflow—from schematic capture to PCB layout and preparation for fabrication.

---

## ✨ Features

- Custom PCB designed in KiCad 10
- NE555 Timer-based circuit
- Compact PCB layout
- Through-hole components
- Simple and beginner-friendly design
- Ready for PCB fabrication

---

## 🔧 Components

| Component | Value |
|-----------|-------|

| Capacitor C1 | 1 nF |
| Capacitor C2 | 100 µF |
| Battery Connector | 2-Pin |
